# 🔥 YOLO Fire Detector - Быстрый старт

## ✅ Проект оптимизирован!

- ONNX Runtime загружается **только при использовании YOLO**
- Основной бандл стал легче
- Динамический импорт компонентов

## 🚀 3 шага для запуска

### Шаг 1: Скопировать WASM файлы

Откройте терминал в папке проекта и выполните:

```bash
mkdir -p public
cp node_modules/onnxruntime-web/dist/*.wasm public/
```

Проверьте:
```bash
ls public/*.wasm
```

Должны появиться файлы: `ort-wasm.wasm`, `ort-wasm-simd.wasm` и др.

### Шаг 2: Получить ONNX модель

**Вариант A: Скачать готовую (быстрее)**

1. Перейдите: https://huggingface.co/SalahALHaismawi/yolov26-fire-detection
2. Скачайте `model.safetensors` или `best.pt`
3. Конвертируйте в ONNX (см. Вариант B)

**Вариант B: Конвертировать из PyTorch**

```bash
# Установите зависимости
pip install ultralytics

# Создайте файл convert.py
cat > convert.py << 'EOF'
from ultralytics import YOLO

# Загрузите модель (укажите путь к вашему файлу)
model = YOLO("best.pt")  # или "model.safetensors"

# Экспорт в ONNX
model.export(format="onnx", opset=12, dynamic=True, simplify=True)
print("✅ Модель конвертирована!")
EOF

# Запустите конвертацию
python convert.py
```

После выполнения появится файл `best.onnx` или `model.onnx`.

### Шаг 3: Разместить модель и запустить

```bash
# Создайте папку для моделей
mkdir -p public/models

# Скопируйте модель
cp best.onnx public/models/fire-smoke.onnx

# Запустите приложение
npm run dev
```

## 🎯 Использование

1. Откройте браузер (обычно http://localhost:5173)
2. Нажмите кнопку **"🔥 YOLO"** в верхней панели
3. **Загрузите модель одним из способов:**
   - **Выбор файла:** Нажмите "Выбрать файл модели" и выберите .onnx файл
   - **По URL:** Введите URL (по умолчанию GitHub) и нажмите "Загрузить по URL"
4. Дождитесь "✓ Модель загружена"
5. Загрузите изображение или видео для тестирования

## 📊 Ожидаемое поведение

- **Первая загрузка YOLO:** ~2-3 секунды (загрузка WASM + модель)
- **Инференс:** 200-500 мс на среднем ПК
- **Точность:** зависит от модели (94.9% для YOLOv26)
- **Классы:** fire (огонь), smoke (дым)

## 🐛 Если предпросмотр не запускается
