# 🎯 Выбор файла модели - Новая функциональность

## Что добавлено

В компонент YOLOFireDetector добавлена кнопка **"Выбрать файл модели"**, которая позволяет загружать .onnx файл напрямую с компьютера через стандартный диалог выбора файла браузера.

## Зачем это нужно

Приложение работает как установленный .exe, и папка `public/models/` недоступна. Теперь не нужно:
- Копировать файлы в специальные папки
- Настраивать пути
- Использовать файловую систему

Просто выберите файл через диалог - и всё работает!

## Как использовать

### Способ 1: Выбор файла (рекомендуется)

1. Откройте приложение
2. Нажмите **"🔥 YOLO"** в верхней панели
3. Нажмите **"Выбрать файл модели"**
4. В открывшемся диалоге выберите .onnx файл
5. Дождитесь "✓ Модель загружена"
6. Готово! Можете тестировать детекцию

### Способ 2: Загрузка по URL

1. Откройте приложение
2. Нажмите **"🔥 YOLO"** в верхней панели
3. Введите URL модели (по умолчанию: GitHub)
4. Нажмите **"Загрузить по URL"**
5. Дождитесь "✓ Модель загружена"
6. Готово!

## Техническая реализация

### Компонент YOLOFireDetector.tsx

```typescript
// Ref для input file
const fileInputRef = useRef<HTMLInputElement>(null);

// Обработчик выбора файла
const handleFileSelect = async (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (!file || !detector) return;

  setLoading(true);
  setError(null);

  try {
    // Создаём object URL для локального файла
    const objectUrl = URL.createObjectURL(file);
    await detector.loadModel(objectUrl);
    setModelLoaded(true);
    setModelUrl(file.name); // Показываем имя файла
    
    // Освобождаем URL после загрузки
    URL.revokeObjectURL(objectUrl);
  } catch (err) {
    setError(`Ошибка загрузки модели: ${err.message}`);
  } finally {
    setLoading(false);
  }
};
```

### UI

```tsx
<div className="flex items-center gap-2">
  <input
    ref={fileInputRef}
    type="file"
    accept=".onnx"
    onChange={handleFileSelect}
    className="hidden"
  />
  <button
    onClick={() => fileInputRef.current?.click()}
    disabled={loading}
    className="px-6 py-2 bg-green-600 hover:bg-green-700 disabled:bg-gray-600 rounded text-white font-semibold"
  >
    Выбрать файл модели
  </button>
  <span className="text-sm text-gray-400">
    или загрузите .onnx файл с компьютера
  </span>
</div>
```

## Преимущества

✅ **Не нужен доступ к файловой системе** - работает в любом окружении  
✅ **Простота использования** - стандартный диалог выбора файла  
✅ **Безопасность** - файл не копируется, используется object URL  
✅ **Совместимость** - работает в браузере, Electron, .exe  
✅ **Два способа загрузки** - файл или URL  

## Как это работает

1. Пользователь нажимает "Выбрать файл модели"
2. Открывается стандартный диалог выбора файла браузера
3. Пользователь выбирает .onnx файл
4. Создаётся временный object URL: `blob:http://...`
5. ONNX Runtime загружает модель по этому URL
6. После загрузки object URL освобождается
7. Модель готова к использованию

## Ограничения

- Поддерживаются только .onnx файлы
- Файл должен быть валидной ONNX моделью
- Размер файла ограничен доступной памятью браузера

## Решение проблем

### Ошибка: "Failed to load model"

**Причина:** Файл не является валидной ONNX моделью

**Решение:**
- Убедитесь что файл имеет расширение .onnx
- Проверьте что модель экспортирована правильно
- Попробуйте другую модель

### Ошибка: "Out of memory"

**Причина:** Модель слишком большая для доступной памяти

**Решение:**
- Используйте более лёгкую модель (YOLOv8n вместо YOLOv8s)
- Закройте другие вкладки браузера
- Перезапустите приложение

### Диалог не открывается

**Причина:** Браузер блокирует диалоги

**Решение:**
- Разрешите диалоги в настройках браузера
- Попробуйте другой браузер
- Используйте загрузку по URL
